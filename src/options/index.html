AriaFox

This add-on does not include aria2. Point it at a JSON-RPC server.

RPC Server Connections

Captured downloads go to the active server, chosen in the manager dropdown.

Server Settings

These live on the aria2 process, not in the add-on. Speed limits are in MiB/s; 0 means unlimited.

Download capture

When capture is on, AriaFox cancels the Firefox download and sends the URL to your aria2 server. Firefox may ask for access to all websites — that is for cookies on those files, not for reading tabs.
